# 规格：R5 —— 配置页返回 + 两个页签的数据共用与热键隔离

版本仍 2.0.1。**只改 Mode2 界面的页签/按钮与热键分派，别碰存储/拒收/导航逻辑。** 不要自己构建。

## 0. 现象与需求（sensei 实测 + 拍板）

1. **配置页（`uiState = 1`）没有返回/退出入口** —— R4 把默认落点改成配置页后，那条路上再没有"回上一层"的按钮。
   **拍板：配置页的「返回」先回子模式页（`uiState = 0`）**（纯客户端页面切换：**不发包、不改模式、不关界面**）。
2. **页签改名**：`物品` → **`存储`**（`gui.ae2addon.mode2.tab_items`）。
   另一个页签**暂时仍叫「拒收」**（sensei 说名字待定；它已经是语言键 `…tab_reject`，只改值即可，别写死中文）。
3. **两个页签共用同一份存储列表，但热键必须隔离**（功能性隔离，不是视觉隔离）：
   - **两页都显示元件里的物品列表**（同一份面板数据）；
   - **收取页额外并上"显式集合"**：`rejectOn ∪ rejectOff` 里那些**元件里已经没有**的 key 也要显示出来
     （用 key 自己的图标/名字渲染，**抽空不消失** ← 这是 R3 死锁修复的延续，不许退化）；
   - **存储页**：只认存储类手势（`Shift+左键`=切无限、`Shift+右键`=切黑名单、`右键`=单物品阈值、
     `Ctrl+左键`=元件内数量）；**`Ctrl+右键`（切拒收）在存储页不生效**；
   - **收取页**：只认收取类手势（`左键`=切拒/允、`Shift+左键`=清除显式设置、`Ctrl+右键`=同"左键"亦可保留）；
     **不触发**任何存储类手势（不切无限、不设阈值、不进黑名单、不设元件内数量）；
   - **hint_bar 按当前页签显示对应那一套**（别再两套混着列）。
4. **`Ctrl+右键` 的设置入口**：因为存储页不再接受它，收取页必须能**新增**拒收条目 ——
   在收取页对"元件里有的物品"按 `左键`/`Ctrl+右键` 即可标记 ✓（本条是实现约束，确保不至于无处可设）。

## 1. 实现要点

- **配置页的「返回」按钮**：
  - 只在 `uiState == 1` 时创建/可见（`uiState == 0` 时隐藏或移除，别和子模式页那个「返回」同时存在）；
  - 点击 = `uiState = 0` + 重建界面（照 `enterWorkMode`/`buildWorkModeSelectUI` 现有的重建方式抄）；
  - **位置不许与任何现有控件重叠**（搜索框、页签、阈值输入、列表、物品栏都算）——
    报告里给出**坐标 + 与相邻控件的间距**，并说明你是怎么核的（用代码里的坐标算，不要"看起来没问题"）。
- **页签与列表**：
  - 页签切换只改"当前页"与热键分派 + 列表内容（收取页并上显式集合），**不许**两套列表各存一份状态导致刷新不一致；
  - 收取页里"元件里没有、但在显式集合里"的条目：图标/名字走 `AEKey`，
    标记沿用 R3 的**红「拒」/ 绿「允」**；这些条目**不许**因为不在元件里就显示成 0 数量异常或空图标；
  - 滚动/分页与现有列表机制共用（别新造一套滚动）。
- **提示行**：页签切换时同步刷新 `hint_bar` 文案（存储页 / 收取页两套）。

## 2. 不许破坏（逐条自检）

1. R3 死锁修复不许退化：**拒收条目在收取页里，抽空后仍然可见、可切回**；
2. R4 导航语义不变：重开 mode 2 → 配置页；子模式页「返回」→ 就地回主模式界面；就地换菜单；`showWorkMode` 走 buffer；
3. 存储页原有手势**行为一字不变**（除了 `Ctrl+右键` 在本页不再触发拒收）；
4. 拒收语义（只拦进不拦出、拒收优先于锁定、物质球内层被拒收整球不吞、`return amount` 锁定语义）不动；
5. S11 布局坐标（面板 72..150 / 编辑控件 151..169 / 物品栏标题 182 / 背包槽 192+ / 快捷栏 250 / `H=276`）不许被压；
6. `extract`/insert 路径 0 改动；`Mode2ConfigPacket` 现有 type 不变（要新 type 就往后加，别改旧号）；
7. 两份 lang JSON 必须可解析。
